# Demand to Workflow

从需求到工作流，这是本课程的核心内容。通过系统化的学习，你将掌握用 n8n 解决任何复杂需求的能力。

## 🎯 课程目标

通过本课程，你将学会：
- 理解 n8n 的底层逻辑和设计思维
- 将任何需求拆解为可执行的工作流
- 掌握 n8n 的核心节点和高级功能
- 独立完成复杂的自动化项目

## 📚 课程结构

本课程共分为 9 个模块，从基础到进阶，循序渐进：

### 基础篇（模块 1-3）
- **模块一**：n8n 基础认知与入门
- **模块二**：n8n 界面概览及核心功能
- **模块三**：n8n 搭建底层逻辑 ⭐（核心）

### 进阶篇（模块 4-6）
- **模块四**：n8n 核心节点精通
- **模块五**：n8n 初阶实战篇
- **模块六**：n8n 辅助技能深化

### 高级篇（模块 7-9）
- **模块七**：n8n 高阶实战篇
- **模块八**：n8n 进阶功能拓展
- **模块九**：n8n 课程 json 模板

## 💡 学习建议

1. **扎实基础**：前三个模块是基础，务必掌握
2. **重点突破**：模块三是核心，需要反复学习
3. **实战为王**：模块五和模块七提供大量实战案例
4. **善用模板**：模块九的 JSON 模板可以直接使用
