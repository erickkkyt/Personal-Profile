## 1. 如何把 JSON 模板导入到 n8n 界面？
<div className="card">
  <div className="card-url">
    <span className="dot dot-blue"></span>
    <span className="card-label">导入步骤</span>
  </div>
  <ul className="faq-steps">
    <li>在 n8n 主页点击右上角 <strong>Import</strong>，或在画布空白处右键选择 <strong>Import from File</strong>。</li>
    <li>选择课程提供的 <code>.json</code> 模板文件，导入后检查节点连线是否完整。</li>
    <li>确认无误后点击 <strong>Save</strong> 或 <strong>Save As</strong>，在左侧给工作流命名并保存版本。</li>
  </ul>
  <VideoPlayer src="f2087f1442e561ef88ebbb8746a8dca0" />
</div>

## 2. 如何连接 n8n 与谷歌表格？
<div className="card">
  <div className="card-url">
    <span className="dot dot-green"></span>
    <span className="card-label">连接步骤</span>
  </div>
  <ul className="faq-steps">
    <li>n8n 里找到对应的 Google Sheets 节点。</li>
    <li>在谷歌云控制台创建项目（<a href="https://console.cloud.google.com/" target="_blank" rel="noreferrer">https://console.cloud.google.com/</a>）。</li>
    <li>在谷歌云控制台开启 API 权限（Google Drive / Google Sheets API）。</li>
    <li>在谷歌云控制台创建 OAuth 密钥。</li>
    <li>输入对应的 URL 和重定向 URL。</li>
    <li>目标对象加入你的邮箱（测试版）或直接对外发布。</li>
    <li>回到 n8n，点击 “Sign in with Google” 测试，即可成功连接。</li>
  </ul>
  <VideoPlayer src="bd07e66af3be647e4f531bdf81c9071a" />
</div>
