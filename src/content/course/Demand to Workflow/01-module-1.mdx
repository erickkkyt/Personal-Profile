## 1.1 AI 自动化的分级与应用，以及 n8n 所处的环节
- **L1 - 基础自动化 (Basic Automation)**  
  - 定义：基于固定规则的流程自动化（RPA），处理重复、明确规则的任务。  
  - 应用：财务报销流程中自动识别发票信息并填入系统。  
  - 局限：缺乏灵活性，无法处理非结构化数据和异常情况。  
- **L2 - 增强自动化 (Enhanced Automation)**——结合 AI 能力  
  - 定义：在基础自动化之上集成 NLP 等 AI 能力，可处理半结构化或非结构化数据。  
  - 应用：自动读取音频转录为文字，并总结会议纪要。  
  - 局限：AI 能力偏工具化，流程主逻辑仍由预设规则驱动。  
- **L3 - 认知自动化 (Cognitive Automation)**——RAG 赋能  
  - 定义：结合 ML/DL，系统可学习、预测和决策，具备一定“认知”能力。  
  - 应用：智能客服理解意图并基于知识库历史数据回复；风控根据行为模式预测欺诈。  
  - 局限：多为特定领域认知，跨领域通用能力有限。  
- **L4 - 自主智能体 (Autonomous Agents)**——母 Agent 调度、子 Agent 执行  
  - 定义：具备目标设定、自主规划、工具调用、执行反思和长期记忆，像虚拟员工。  
  - 应用：给定预算与目的地，Agent 自主搜索、预订、规划并输出完整行程计划。  

- **n8n 的定位：AI 时代的“中枢神经系统”**  
  - 贯穿 L2–L4 的核心编排层。  
  - L2：连接和调度不同 AI 工具（OCR、NLP 等）。  
  - L3：将模型预测结果接入流程并触发业务动作（如高流失风险自动邮件关怀 + 客户经理提醒）。  
  - L4：充当 Agent 的“神经网络”。LLM 负责思考规划，n8n 通过节点调用具体工具（如 Gmail 节点）完成动作，粘合各类 API/服务以执行复杂任务。  

## 1.2 n8n 是什么？

- **核心概念**：源代码可用的工作流自动化平台，低代码/可视化拖拽，连接应用/服务/API，实现自动化、数据集成、AI 流程编排；支持自托管与云部署。  
- **基础特点**  
  - 生态丰富：400+ 内置节点 + HTTP 任意 Web 服务。  
  - 操作简单：可视化编辑器，支持条件、分支、循环、批处理等。  
  - 提高上限：支持自定义 JavaScript。  
  - 深度结合 AI：内置 AI 节点，原生集成 LangChain。  
  - 使用方式多元：自托管、云端、企业版可选。  
  - 适配企业：安全、版本控制、团队协作、错误处理等。  
- **稳定性机制**  
  - 错误处理：错误触发器 + 备用流程（通知、记录日志等）。  
  - 调试机制：Executions 记录，逐步查看每步输入输出。  
  - 自动重试：节点可配置失败重试次数与间隔。  
  - 版本控制：自动保存历史，可随时回滚。  

## 1.3 为什么学习 n8n 而不是其他工作流软件？

- **n8n 与核心竞对**  
  - n8n：定制/可拓展强，需要一定学习成本与逻辑思维。  
  - Coze：适配国内平台，可拓展性弱，海外适配低，上手简单。  
  - Dify：功能多且开源，体验与能力略弱于 n8n。  
  - Zapier：老牌工作流，生态成熟，AI 支持弱于 n8n。  
- **开源优势的商业价值**  
  - 数据主权：可私有化部署，数据留在企业内。  
  - 定制能力：自定义节点接入内部系统。  
  - 成本控制：自托管以固定服务器成本支撑高并发。  
- **AI 时代的独特价值**：成为 AI Agent 的“神经网络”，越强的 LLM 只会增强 n8n 的编排能力。  
- **母公司概况**：ARR 约 4000 万美元，25 年搜索量 10 倍增长，累计融资数亿欧元，投资方 Accel 等。  

## 1.4 n8n 的安装与环境配置

- 常见使用方式：官网云、第三方 PaaS、自建云服务器、本地部署。  
- 部署对比概览：  
  - 官网云：极低门槛，14 天免费，后续付费。  
  - PaaS（Zeabur/Clawcloud 等）：低成本一键部署，入门门槛低。  
  - 云服务器 + Docker：成本低、可 7x24，需基础运维/Docker 知识。  
  - 本地桌面：零成本，适合学习/测试，依赖本机运行。  
- 使用方式示例：  
  - 官网注册（14 天免费）；  
  - 本地 Docker 部署；  
  - 云托管平台部署。
